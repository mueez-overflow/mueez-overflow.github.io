Refactored portfolio
====================

Files:
- index.html         All portfolio information/content. Edit bio, links, publications,
                     education, experience, and projects here.
- site.css           Presentation/layout only.
- site.js            Behavior only (theme, active header item, image parallax).
- favicon.svg        Favicon.
- observer-coast.gif Profile/observation image.

content.js is intentionally removed. No portfolio content is generated from JavaScript.
